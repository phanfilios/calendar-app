# Minimal Calendar App

Una aplicación de calendario elegante y minimalista para iOS y Android construida con React Native.

## Características

- 📅 **Vista de calendario** con navegación por meses
- ✨ **Gestión de eventos** (crear, editar, eliminar)
- 🌙 **Modo oscuro** con persistencia
- 📱 **Diseño responsive** para iOS y Android
- 💾 **Persistencia local** con AsyncStorage
- 🎨 **Animaciones suaves** y transiciones
- 🔔 **Recordatorios** de eventos del día

## Requisitos Previos

- Node.js >= 16
- React Native CLI
- Android Studio (para Android)
- Xcode (para iOS - solo Mac)
